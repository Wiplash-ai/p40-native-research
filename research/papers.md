# Literature and claim-to-source ledger

Access date: 2026-09-07. This is a decision-oriented discovery survey, not an exhaustive literature review. Sources are original papers, author repositories and first-party hardware/model documentation. Dates below are paper first submissions unless marked otherwise; mutable model cards/repos must be revision-pinned before implementation. Architectural performance implications are hypotheses for P40, not source-reported P40 benchmarks.

## Architectures, mathematical primitives and their weaknesses

| Source / date | Dominant operations and memory | P40 opportunity and limitation |
|---|---|---|
| Gu et al., [S4](https://arxiv.org/abs/2111.00396), 2021 | Structured state transitions, Cauchy kernels, FFT/complex convolution for training; fixed recurrent state for decode | Ordinary CUDA possible; DP4A only helps quantized projections. Complex discretization/FFT is not an integer-dot workload |
| Gu & Dao, [Mamba](https://arxiv.org/abs/2312.00752), 2023-12-01 | Selective scan, dense projections, short conv, state O(DN); sequential decode, parallel scan training | Fuse recurrence/state movement; quantize projections first. Input-dependent decays and state errors need FP32 control |
| Dao & Gu, [Mamba-2 / SSD](https://arxiv.org/abs/2405.21060), 2024-05-31 | Structured recurrence and chunk matrix products | Its Tensor-Core-oriented parallel kernel speed is not a P40 prediction. Decode formulation remains interesting; measure chunk overhead |
| Lahoti et al., [Mamba-3](https://arxiv.org/abs/2603.15569), 2026-03-16 | More expressive discretization, rotations/complex dynamics and SISO/MIMO recurrence | Verified current work. Additional useful arithmetic per state byte is directly relevant, but H100-oriented kernels/batch results do not establish Pascal efficiency; SISO first |
| Peng et al., [RWKV-5 Eagle / RWKV-6 Finch](https://arxiv.org/abs/2404.05892), 2024-04-08 | Multi-head matrix states, outer products, decay, channel/time projections | Constant context-state size but O(Hn²) traffic. INT8 projections plausible; state update is not a DP4A GEMM |
| Peng et al., [RWKV-7](https://arxiv.org/abs/2503.14456), 2025-03-18 | Generalized delta-rule matrix recurrence and gates | Strong reference for state tracking. Preserve FP32 state while testing projection math; chunk training kernels must be checked for sm61 |
| BlinkDL, [RWKV-8 Heron ROSA demo](https://github.com/BlinkDL/RWKV-LM/blob/main/RWKV-v8/260222_rosa4bitLM_L12.py), undated source with 2026-02-22 filename | Sign-derived discrete symbols, sequence matching plus floating projections | Experimental implementation verified; production architecture/maturity unverified. “4bit” symbols do not mean four-bit weights or constant-state inference |
| Li et al., [Diffusion-LM](https://arxiv.org/abs/2205.14217), 2022 | Continuous denoising and Transformer computation over text representations | More parallel output but many passes. Compare complete-answer latency and achieved quality, not isolated denoiser tokens |
| Nie et al., [LLaDA](https://arxiv.org/abs/2502.09992), 2025-02-14 | Bidirectional masked-token Transformer, iterative refinement | Reuses weights over more token rows; repeated attention/projections cost compute. Requires diffusion training, not an inference flag |
| Dream authors, [Dream 7B](https://arxiv.org/abs/2508.15487), 2025-08-21 | Discrete iterative denoising | AR initialization followed by diffusion training demonstrates adaptation, not free conversion. Test steps-vs-quality at tiny scale |
| Google DeepMind, [DiffusionGemma model card](https://ai.google.dev/gemma/docs/diffusiongemma/model_card), accessed 2026-09-07 | MoE encoder caches context; bidirectional 256-token decoder canvases; completed canvas extends KV | Verified released model. Does use a KV cache. Reported H100 FP8 speed is not DP4A/P40 evidence; include all denoising passes |
| Wang et al., [BitNet](https://arxiv.org/abs/2310.11453), 2023-10-17; Ma et al., [BitNet b1.58](https://arxiv.org/abs/2402.17764), 2024-02-27 | Binary/ternary linear weights and quantized activations, still Transformer attention | Add/subtract or DP4A-expanded ternary possible. Packing, gates, scaling and optimizer cost remain. Train around quantization; naïve ternary rounding of Qwen is not validated |
| Zhu et al., [Scalable MatMul-free Language Modeling](https://arxiv.org/abs/2406.02528), 2024-06-04, revised 2025-07-25 | Ternary projections, gated vector recurrence, channel mixing | Direct prior art for replacing multiply-heavy linear layers. Reduction/memory costs persist; small state can bottleneck retrieval. Neuromorphic wins do not transfer automatically to P40 |
| Wei et al., [T-MAC](https://arxiv.org/abs/2407.00088), 2024 | Activation-sum lookup tables indexed by weight bits | CPU SIMD results motivate a GPU hypothesis. DP4A does not accelerate table lookup; shared-memory design and build amortization decide viability |
| Park et al., [LUT-GEMM](https://arxiv.org/abs/2206.09557), 2022-06-20, ICLR version 2024 | Binary-coded quantized weights, shared LUTs and scaled accumulation | Direct GPU precedent for multiplication replacement. Table/bank bandwidth and batch-size tradeoffs can outweigh reduced dequantization |
| Egiazarian et al., [AQLM](https://arxiv.org/abs/2401.06118), 2024-01-11 | Additive vector codebooks plus discrete indices | Saves weight bytes with calibrated compression. Indices are not INT8 operands; codebook/reconstruction traffic must be measured. Separate codebook fitting from inference |
| MoM authors, [Mixture-of-Memories](https://arxiv.org/abs/2502.13685), 2025-02-19 | Routes tokens to selected delta-rule memory banks, with shared memory | Expert locality may save touched state. Allocated state grows with all banks; routing/gather/scatter can dominate small kernels and needs training |
| Kamahori et al., [Fiddler](https://arxiv.org/abs/2402.07033), 2024-02-10 | CPU/GPU MoE orchestration; execute cold experts on CPU to avoid weight transfers | Strong prior work for stationary weights and moving small activations. GPU-only math can lose if it forces large PCIe transfers |
| Song et al., [PowerInfer](https://arxiv.org/abs/2312.12456), 2023-12-16 | Hot/cold neuron locality with GPU/CPU sparse execution | Sparsity/locality is workload/model dependent. Do not assume ordinary Qwen/Kimi weights exhibit the required sparse-neuron behavior |
| Dao et al., [FlashAttention](https://arxiv.org/abs/2205.14135), 2022 | Tiled QK/softmax/V with less global-memory traffic | IO-aware math ordering applies to Pascal; current optimized libraries may not support it. Avoid materializing O(T²) scores even when using FP32 CUDA |
| Eldan & Li, [TinyStories](https://arxiv.org/abs/2305.07759), 2023 | Small-model language-learning dataset/experimental precedent | Cheap initial learning check; not evidence of agent/coding capability. Pair with held-out text and explicit retrieval/state tests |

The first six recurrent families do not mathematically require Tensor Cores, but their released fast implementations may require newer GPUs. SSM/RWKV decoding often faces state/projection bandwidth and launch costs; parallel training/prefill can instead be compute-bound. Diffusion can increase arithmetic intensity via multiple rows yet multiply total computation. Sparse models save active weight reads only if routing/locality and memory layout cooperate. None is classified universally compute- or bandwidth-bound without shapes, batch, context and measured timings.

## Research gaps and stopping decision

Searches covered exact latest named variants (Mamba-3, RWKV-8, DiffusionGemma, Qwen3.6, Kimi K3), low-bit/lookup prior art, recurrent memory banks, hybrid offload, Pascal specs and compatibility. Two bounded research lanes were reconciled with installed source and server observations. High-impact claims were spot-checked against source code, planner/header arithmetic and official model/hardware pages.

Discovery stops here because remaining decision-changing unknowns need measurement: thermals, CPU-stage proportions, actual kernel efficiency, lookup break-even, low-bit recurrence quality, expert reuse, profiler support and multi-GPU traffic. An exhaustive newer-method census would not resolve those. RWKV-8 maturity, exact P40 cache capacities, exact K3 checkpoint bytes, and long-term 4-GPU topology remain explicit gaps. No novelty claim is supported at this stage.
